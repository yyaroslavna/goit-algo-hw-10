## Завдання 1. Жадібний алгоритм та динамічне програмування

Було реалізовано два алгоритми для видачі решти покупцеві.

### Жадібний алгоритм

Функція `find_coins_greedy()` використовує найбільші номінали монет першими.

Переваги:
- Простий у реалізації.
- Швидко виконується.
- Не потребує великої кількості пам'яті.

Складність:
- Часова складність: O(k), де k — кількість номіналів монет.
- Просторова складність: O(k) для результату.

### Динамічне програмування

Функція `find_min_coins()` перевіряє різні варіанти формування суми та знаходить мінімальну кількість монет.

Переваги:
- Знаходить оптимальний результат.
- Працює навіть тоді, коли жадібний алгоритм не знаходить оптимального рішення.

Недоліки:
- Потребує більше часу.
- Використовує додаткову пам'ять.

Складність:
- Часова складність: O(n * k).
- Просторова складність: O(n).

Де n — сума, яку потрібно видати, k — кількість номіналів монет.

### Порівняння алгоритмів

Жадібний алгоритм працює швидше, оскільки просто перебирає номінали монет від найбільшого до найменшого.
Динамічне програмування потребує більше обчислень, оскільки перевіряє можливі варіанти формування суми.
Для заданого набору монет обидва алгоритми дають оптимальний результат.
При великих сумах жадібний алгоритм буде ефективнішим за часом та використанням пам'яті.

## Завдання 2. Метод Монте-Карло

Для обчислення інтеграла було використано функцію:

f(x) = x^2

Межі інтегрування: від 0 до 2.
Для обчислення використано метод Монте-Карло з 100000 випадкових точок.

### Порівняння результатів

Аналітичне обчислення:

∫(від 0 до 2) x^2 dx = 8/3 ≈ 2.6667

Метод Монте-Карло дає приблизне значення інтеграла, яке може трохи відрізнятися від аналітичного результату.

### Висновок

Метод Монте-Карло дозволяє приблизно обчислити визначений інтеграл за допомогою випадкових чисел.
Порівняння показує, що результат методу Монте-Карло наближений до аналітичного значення.
Збільшення кількості випадкових точок зазвичай підвищує точність обчислень.
Отже, метод Монте-Карло можна використовувати для наближеного обчислення інтегралів.
